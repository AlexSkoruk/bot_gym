# bot_gym
Bot Gym: Telegram-бот для подбора персональных тренеров по фитнесу

Описание:
Bot Gym — это Telegram-бот, предназначенный для мэтчинга спортсменов (клиентов) и тренеров по фитнесу/силовым видам спорта. Бот собирает анкеты от пользователей двух ролей, выполняет поиск подходящих пар, обрабатывает отзывы и обратную связь.
Включает:

Telegram-бот на базе Telebot для взаимодействия с пользователями.
Админ-панель на Flask для модерации тренеров, просмотра анкет и статистики.
База данных SQLite для хранения данных.
Поддержка загрузки фото, множественного выбора (цели, локации).

Проект ориентирован на нишу фитнеса: подбор по целям (похудение, набор массы и т.д.), формату (онлайн/оффлайн), городу и уровню подготовки.

Функциональность:
Для спортсменов (клиентов):

Заполнение анкеты: контакт, ФИО, возраст, пол, вес, рост, уровень подготовки, цели, формат тренировок, ограничения по здоровью, город/локация.
Поиск тренера: автоматический мэтчинг по критериям.
Обратная связь: отзывы после матча (связь, тренировка, оценка).
Меню: просмотр своей анкеты, смена тренера.

Для тренеров:

Заполнение анкеты: контакт, ФИО, дата рождения, о себе, фото квалификации/личные фото, ссылки на соцсети, цели работы, формат, локации.
Модерация: админ подтверждает квалификацию.
Поиск учеников: активный/пассивный режим, лимит по ученикам.
Обратная связь: отзывы о клиентах.

Админ-панель (Flask):

Просмотр списка тренеров/спортсменов.
Модерация квалификации тренеров.
Просмотр карточек пользователей с фото.
Отправка уведомлений в бот.

Технологии

Язык: Python 3.x
Библиотеки для бота: pyTelegramBotAPI (telebot), SQLite3
Веб-админка: Flask, html, Jinja2
База данных: SQLite
Дополнительно: datetime, math, requests
